# Blog API Contract

The frontend blog defaults to the admin-service origin:
`https://api.admin.dailyfood.app`.

Set `VITE_API_BASE_URL` or `VITE_BLOG_API_BASE_URL` to override that origin in
local or staging environments.

## Public Endpoints

### `GET /api/v1/blogs?status=published`

Returns published blog posts for `/blog`.

Accepted response shapes:

```json
[{ "id": "1", "slug": "weekly-grocery-savings", "title": "..." }]
```

```json
{ "data": [{ "id": "1", "slug": "weekly-grocery-savings", "title": "..." }] }
```

The frontend also accepts `blogs`, `posts`, or `items` as the list key.

### `GET /api/v1/blogs/:slug`

Returns one published blog post for `/blog/:slug`.

Accepted response shapes:

```json
{ "id": "1", "slug": "weekly-grocery-savings", "title": "..." }
```

```json
{ "data": { "id": "1", "slug": "weekly-grocery-savings", "title": "..." } }
```

The frontend also accepts `blog`, `post`, or `item` as the object key.

## Admin Endpoints

All admin endpoints should require authentication server-side. The admin app
uses the active admin session token and calls these endpoints from `/blogs` and
`/blogs/editor`.

### `GET /api/v1/admin/blogs`

Returns draft and published blog posts.

### `POST /api/v1/admin/blogs`

Creates a blog post.

### `PATCH /api/v1/admin/blogs/:id`

Updates a blog post.

### `DELETE /api/v1/admin/blogs/:id`

Deletes a blog post.

## Blog Fields

```json
{
  "id": "string",
  "slug": "string",
  "title": "string",
  "excerpt": "string",
  "content": "<p>Rich text HTML generated by the admin editor.</p>",
  "authorName": "DailyFood Team",
  "category": "Food Savings",
  "tags": ["food savings", "grocery planning"],
  "status": "draft",
  "coverImageUrl": "https://example.com/image.jpg",
  "seoTitle": "Search title under 60 characters",
  "seoDescription": "Search description under 160 characters",
  "canonicalUrl": "https://dailyfood.app/blog/weekly-grocery-savings",
  "publishedAt": "2026-09-15T12:00:00.000Z",
  "updatedAt": "2026-09-15T12:00:00.000Z",
  "readingTimeMinutes": 4
}
```

Snake case alternatives such as `author_name`, `cover_image_url`,
`seo_title`, `seo_description`, `canonical_url`, `published_at`, and
`reading_time_minutes` are also normalized by the frontend.

## SEO Notes

The frontend sets page titles, meta descriptions, canonical tags, Open Graph,
Twitter summary tags, and JSON-LD for blog index and article pages.

The public article page sanitizes stored HTML before rendering it.

For stronger crawl coverage after the backend exists, add every published blog
slug to `sitemap.xml` or expose a generated sitemap endpoint that includes
`https://dailyfood.app/blog/:slug` URLs.
